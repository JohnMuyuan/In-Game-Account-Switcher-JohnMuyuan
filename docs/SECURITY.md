# Security Policy

## Supported Version

Security fixes are provided for the latest source and release of In-Game Account Switcher: JohnMuyuan Edited Version. The currently verified targets are Fabric for Minecraft 1.20.1, 26.1.2, and 26.2, and Forge for Minecraft 1.20.1, 26.1.2, and 26.2.

Other Minecraft versions and loader combinations are not supported by this edited version, even when inherited source files for them remain in the repository.

## Reporting a Vulnerability

Do not open a public issue containing passwords, Microsoft tokens, account files, unredacted logs, or other private data.

Use the repository's GitHub Security tab to submit a private vulnerability report. Include the affected version, reproduction steps, expected behavior, and the smallest possible redacted log excerpt. Never attach `_IAS_ACCOUNTS_DO_NOT_SEND_TO_ANYONE` or `global_password_v2`.

For ordinary non-sensitive bugs, use the repository's public issue tracker and remove account names, UUIDs, tokens, local paths, and other personal information first.
